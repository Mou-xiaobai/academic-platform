Method

它怎么做到的

四步流水线

  1. 解析版面：PyMuPDF 取出每个文本块的坐标、字号、字体，块就是天然的翻译单元。
  2. 切分清洗：重连断行（软连字符/硬连字符），跳过页眉页脚、页码、作者单位、参考文献、公式。
  3. 逐块翻译：注入术语表，按 JSON 契约批量翻译并校验，失败自动降级补译。
  4. 重排版面：Redaction 抹掉英文字形（图片与矢量线条保留），用宋体/黑体/楷体在原框内重绘中文，按框自适应字号、行距与两端对齐。

已知边界：图内文字是位图，不会翻译；参考文献保持原文；公式上下标沿用原 PDF 的纯文本形态； 中文比英文紧凑，段落末尾会留下少量空白——这是「原地保版式」的代价，换来的是零重排、零错位。

在线阅读与中英对比

任务完成后可打开内置阅读器：连续滚动阅读原文或中文译文，一键切换「中英对比」双栏同步浏览； 支持缩放、适应宽度与页码跳转。「记录」里的历史任务也能随时打开阅读。翻译进行中也可以先读原文。
